# APK release

ChiTieu-2.0.0-release.apk là bản release đã ký, package vn.chitieu. SHA-256 nằm trong SHA256SUMS.txt.

Khoá release được giữ riêng trên máy phát triển, không có trong repository. Các bản cập nhật tiếp theo cần dùng cùng khoá ký.

## Bản thử nghiệm 2.1.0-beta.1

Tải APK đã ký và SHA-256 từ [GitHub pre-release](https://github.com/hawlzz/ChiTieu/releases/tag/v2.1.0-beta.1). APK thử nghiệm được đính kèm release, không thêm bản nhị phân mới vào lịch sử Git.
